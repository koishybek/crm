# Home Max Service — CRM для сервисной компании

CRM для компании, которая принимает заявки на ремонт и сервис (кондиционеры, техника, сантехника, электрика…) и отдаёт заказы выездным мастерам. Компания зарабатывает на разнице между ценой для клиента и выплатой мастеру.

- **Операторы** принимают заявки (сайт, OLX, WhatsApp, Telegram, звонки), превращают их в заказы и следят за сроками.
- **Мастера** берут заказы из ленты или в Telegram одной кнопкой и ведут их до «Выполнено».
- **Владелец** видит выручку, маржу, долги клиентов, выплаты мастерам и аналитику.
- **AI** расшифровывает звонки и голосовые сообщения и раскладывает обращение по полям заявки.

## Состав

| Папка | Что внутри |
|---|---|
| [`web/`](web/) | Приложение: React 19 + Vite + Tailwind 4 (статикой на Cloudflare Workers) и бэкенд на Convex — база, функции, Telegram-бот, вебхук АТС. Подробно — [web/README.md](web/README.md) |
| [`ai-service/`](ai-service/) | Cloudflare Worker на Workers AI: расшифровка записей (Whisper large v3 turbo) и разбор обращения в черновик заявки (Llama 3.3 70B) |

## Запуск

```bash
cd web
npm install
npm run convex   # функции → свой dev-деплоймент Convex
npm run dev      # http://localhost:5190
npm test         # серверные тесты
```

Секреты (токен бота, ключ AI-сервиса) в репозиторий не входят: они в `web/.env.local`, `ai-service/.dev.vars*` и в переменных окружения Convex — см. [web/README.md](web/README.md).
